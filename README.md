# Conecta Soledad +60

Blog del Proyecto de Humanidades Digitales (Práctica en Responsabilidad Social, UNIMINUTO).
Autora: Laura Vanessa Bornacelli Parra.

## Publicar en GitHub Pages
1. Crea un repositorio público llamado `conecta-soledad` y sube todo el contenido de esta carpeta (index.html debe quedar en la raíz).
2. En el repositorio ve a **Settings → Pages**.
3. En "Build and deployment" elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`. Guarda.
4. Espera 1 o 2 minutos. El enlace queda así: `https://TU-USUARIO.github.io/conecta-soledad/`

## Estructura
- `index.html`: inicio, entradas y "Sobre mí"
- `entrada-1.html`: presentación, guía multidimensional y plan de trabajo
- `entrada-2.html`: problemática, contexto, mapa, objetivos y justificación
- `styles.css`: estilos
- `img/`: imágenes
